Comment il travaille

Il agit, puis il vérifie.

Une vraie boucle de travail, pas une simple réponse.

  1. Il comprend l'objectifIl ne pose une question que si une information indispensable manque.
  2. Il choisit le bon outilLe terminal pour les fichiers, l'écran pour les interfaces, le web pour l'actualité.
  3. Il agit et contrôleIl relit le fichier, relance le programme, prend une capture d'écran.
  4. Il te rend compteCe qui a été fait, où se trouve le résultat, ce qui reste à faire.
Sécurité

Tu gardes la main, toujours.

Tu choisis jusqu'où il peut aller seul. Pour le reste, il te demande la permission, et tu peux l'arrêter à tout instant.

Prudent

Demande avant chaque commande, modification ou clic.

Équilibré

Agit librement, mais demande pour les suppressions, les envois et tout ce qui touche au système.

Autonome

Ne t'interrompt que pour les actions catastrophiques.

  • Bouton Stop, ou souris dans un coin de l'écran : arrêt immédiat
  • Chaque fichier modifié est sauvegardé avant
  • Les suppressions passent par la corbeille
  • Interface accessible depuis ton PC uniquement, avec un jeton secret
  • Les consignes cachées dans une page web ou un e-mail sont ignorées
  • Il ne saisit jamais tes mots de passe ni tes codes bancaires
Installation

Prêt en cinq minutes.

Atlas tourne sur ton ordinateur. Tes fichiers ne quittent ta machine que pour ce qu'il doit faire, envoyés à l'API d'Anthropic.

Windows double-clic
  1. Décompresse Atlas-assistant-IA.zip
  2. Lance installer_windows.bat
  3. Lance demarrer_windows.bat : le navigateur s'ouvre
  4. Colle ta clé API dans ⚙ Réglages
macOS · Linux terminal
  1. Décompresse l'archive
  2. ./installer.sh
  3. ./demarrer.sh
  4. macOS : autorise Accessibilité et Enregistrement de l'écran
Python 3.10+python.org, en cochant « Add to PATH » sous Windows
Clé API Anthropicconsole.anthropic.com, facturation à l'usage
Node.js (conseillé)Pour connecter tes applications via MCP
