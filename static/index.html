Le modèle, les outils et les instructions s'appliquent aux nouvelles conversations. Le mode d'autorisation s'applique tout de suite.

Atlas essaie les modèles activés dans l'ordre de priorité (1 = en premier). Si l'un échoue (plus de crédit, coupure, service en panne), il passe automatiquement au suivant. Seul Claude contrôle l'écran ; les autres gardent le terminal, les fichiers, le web et les connecteurs.
